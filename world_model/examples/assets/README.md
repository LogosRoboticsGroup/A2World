# Local Rollout Samples

The sample inputs are provided for running the released checkpoints locally.

## Pretrained

- `pretrained/agibot/`: left wrist, head, and right wrist views with 20 action steps
- `pretrained/droid/`: two exterior views and one wrist view with 20 action steps
- `pretrained/robocoin/`: high, left wrist, and right wrist views with 20 action steps
